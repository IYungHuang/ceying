# 角色配置與交接

| 角色 | 職責 | 交付 | 邊界 |
|---|---|---|---|
| 總編輯 | 設定題旨、檢核證據、裁定敘事可用範圍 | 專案規則、核定基線、決策清單 | 不以戲劇需求改寫已核實史實 |
| continuity_editor | 獨立查證事件、時序、官職、技術與史料分歧 | 證據表、禁寫成定論項目 | 不寫小說情節 |
| novelist | 依總編輯交付的基線提出三種主角與章綱 | 比較表、情節提案與獲授權後的章節草稿 | 不自行宣布爭議史實已確定；正式章節依使用者授權與總編輯交接寫作 |

交接時，總編輯提供附來源的核定基線及未決問題。作者回傳每一方案對史實的依賴與虛構設定。總編輯逐項核對後交付讀者決策。

本專案使用兩個獨立子agent session。使用者後來已將兩份角色 TOML 安裝於 `.codex/agents/`，本輪核對檔案存在且與[安裝包](../agent_profiles/README.md)相同。新 session 可依角色名稱指派任務；角色檔不會自行持續執行或在回合結束後背景回報。每輪由總編輯分派範圍、追蹤交付並整合審核；當次工作狀態以實際 agent session 為準。
