# 第六章〈覆算〉場景提案

狀態：總編輯已按[第六章史實預查](../research/chapter6_preflight.md)核定並交作者。章節維持許知衡第三人稱限知，所有他經手的本監抄件與差遣屬小說虛構。

1. **舊樣仍在案上。** 三日測影後，許知衡仍須照既有曆樣做事。曹先生給他一份康熙八年曆稿的監內副本，並告知南懷仁奉命查對吳明烜稿；他只核欄位與轉抄，不代朝廷判曆法、教事或葬期案件。
2. **續驗與職務的不同步。** 立春、雨水、太陰及火木星等續驗消息經曹先生或監內存件傳到曆科。許知衡在兩份抄目旁分記「所測相符」與「誰仍供職」；避免把康熙七年十一月三日表影寫成當日改官。官題的「逐款皆符／皆錯」是題報措辭，不是主角親見全部現場。
3. **同一欄被兩次命令拉動。** 朝廷討論九十六刻、九年曆交南推與紫炁是否開寫，原先要刪的欄後又奉旨照舊。讓鄧起提出可交出去的短抄目，許知衡須留下命令日期與所適用曆年；兩人的分歧關乎稿件能否用，不設定一方代表進步、另一方代表愚昧。
4. **置閏修改落到紙上。** 八年已頒曆載閏十二月，後議取消，改作九年正月並在九年閏二月；中間須經部議、問監官、奉旨。若寫入正文，依清曆三月十二日旨的決定，不把南懷仁最初論說直接寫成頒行結果。
5. **三欄結尾。** 許知衡私簿分「算得合」「官職移轉」「案由翻轉」三欄。第一欄可核算與題報，第二欄依公告或本監交辦，第三欄僅憑可指明來處的消息；不寫一句「都平反了」。五名中國籍職官之死仍是不能由新曆稿補回的事。

取捨：本章可集中於康熙八年正月至三月的本監曆稿，不必逐一重演所有觀測。若涉及西曆三月、九月法律翻案，須明說消息途徑；清曆日期未逐條對合前，不作精確對譯。南懷仁的職銜只按當時題奏／諭旨書寫，勿提前稱監正。
