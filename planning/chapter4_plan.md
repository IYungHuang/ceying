# 第四章〈候影〉場景節拍

本頁為 novelist 提案、總編輯依 [第四章史實核定](../research/chapter4_preflight.md)修正後的寫作藍圖；具體場景與人物言語均屬小說虛構。

1. **兩年過橋**：1666 年秋後至 1668 年歲暮，許知衡仍是曆科食糧天文生。透過新舊稿同案核抄、舊落款再被取出，呈現監內人事與曆務逐漸改向。家計只用一兩個具體動作帶過，不重演前三章飯桌問答。
2. **受命備欄**：康熙七年十一月下旬，曹先生交辦監內待填測驗抄條。主角只知翌日正午要測表影，檢查日期、時刻、表高、預推、臨測、經手與來處等空欄。這張紙及差遣無史料實證，須在編輯註標 F。
3. **空欄分量**：鄧起問空欄是否占紙、摘要何以能趕交；許知衡指出沒有表高與影長的對照，日後「準」字無從覆核。曹先生只裁定本監抄條格式，不代御前或驗官下結論。此衝突仍是三名虛構人物之間的工作討論。
4. **章末待測**：交出未填的準備抄條，主角記下自己實際經手與消息來處；停在 26 日夜，不寫首日實數、結果、影端異議或後兩日續測命令。

前三章連續性：許知衡私簿已有「未覆校」「摘字須記原在何處」「只記親見」「曹先生言／未見原牘」等工作記錄；他在第三章兩次落「許知衡謄校」。第一、二章的虛構漏註、紙籤與第三章淡墨疑點，均不得成為測影或曆獄史實因果。
