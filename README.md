# 《測影》

康熙曆獄及其後續觀測與平反為歷史基線的中篇小說專案。第一階段的史料核查、人物方案與章綱提案已完成。已選定 A：虛構欽天監曆科食糧天文生，受命抄核算稿；結尾延至 1671 年。七章正文已依讀者回饋完成 B＋C 結構重寫，並由作者逐章改稿、查證編輯逐章複核。

[閱讀《測影》全稿](manuscript/測影-全稿.md)：七章合卷，32,340 字元；各章編輯註另存。重寫前版本保存在 [revisions/before-structural-rewrite](revisions/before-structural-rewrite/)。

## 創作目標

以曆算、觀測、文書校對等專業工作如何被轉成政治證據為主軸，呈現工作者、官署與信仰共同受牽連的過程。各方人物須有可理解的制度利益與生存壓力，避免「科學英雄擊敗愚昧反派」的簡化敘事。

[逐章進度](planning/progress.md)記錄查證、正文修訂與審校的實際完成狀態。
[B＋C 結構重寫規格](planning/revision_design.md)記錄主角欲望、失誤代價與七章調整。
